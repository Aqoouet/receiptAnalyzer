# Скрипты для освобождения портов

Этот набор скриптов предназначен для автоматического освобождения портов, указанных в конфигурационном файле `config.yaml`.

## Файлы

- `free_ports.sh` - Интерактивный скрипт с запросом подтверждения
- `free_ports_auto.sh` - Автоматический скрипт без запроса подтверждения

## Использование

### Интерактивный режим
```bash
./free_ports.sh [config_file]
```

### Автоматический режим
```bash
./free_ports_auto.sh [config_file]
```

### Параметры
- `config_file` - путь к конфигурационному файлу (по умолчанию: `config.yaml`)

## Поддерживаемые порты

Скрипты автоматически находят и освобождают следующие порты из секции `ports` в config.yaml:

- `mailfetcher` - порт для сервиса получения почты
- `htmlimporter` - порт для сервиса импорта HTML
- `xlsxexporter` - порт для сервиса экспорта в Excel
- `qwencategorizer` - порт для сервиса категоризации

## Пример конфигурации

```yaml
ports:
  mailfetcher: 8081
  htmlimporter: 8082
  xlsxexporter: 8083
  qwencategorizer: 8084
```

## Функциональность

### Что делает скрипт:

1. **Анализ конфигурации** - читает порты из config.yaml
2. **Проверка занятости** - определяет, какие порты заняты процессами
3. **Информация о процессах** - показывает детали процессов, использующих порты
4. **Безопасное завершение** - сначала отправляет SIGTERM, затем SIGKILL при необходимости
5. **Подтверждение** - в интерактивном режиме запрашивает подтверждение для каждого порта
6. **Отчет** - показывает финальный статус всех портов

### Безопасность:

- Использует `lsof` для безопасного определения процессов
- Сначала пытается корректно завершить процессы (SIGTERM)
- Принудительно завершает только при необходимости (SIGKILL)
- Показывает информацию о процессах перед завершением

## Примеры использования

### Освобождение всех портов автоматически:
```bash
./free_ports_auto.sh
```

### Освобождение портов с кастомным конфигом:
```bash
./free_ports.sh my_config.yaml
```

### Проверка статуса портов:
```bash
# После выполнения скрипта будет показан финальный статус
./free_ports_auto.sh
```

## Требования

- Bash 4.0+ (для ассоциативных массивов)
- `lsof` - для определения процессов на портах
- Доступ к завершению процессов (обычно требует прав пользователя)

## Обработка ошибок

- Проверка существования конфигурационного файла
- Проверка наличия секции с портами
- Graceful handling ошибок при завершении процессов
- Информативные сообщения об ошибках

## Интеграция

Скрипты можно интегрировать в:
- CI/CD пайплайны
- Скрипты развертывания
- Автоматические тесты
- Процессы перезапуска сервисов
